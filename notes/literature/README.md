## Search limits

Discovery used web searches by exact titles, author names, “rainbow number,”
“anti-Ramsey matching,” “arithmetic progression,” “color-coding,” and “expander,”
followed by author/institution-hosted PDFs, arXiv, and publisher records.
References in OY13 and LTJ09 supplied backward links. A second pass compared
matching threshold conventions and the host graphs; it was by the same reviewer.
Forward citations, MathSciNet, and zbMATH were not systematically covered.

Recent regular-bipartite papers and later work on the hypergraph conjecture were
located, but their precise statements were not verified here. We do not call
the historical conjectures currently open. No research question in this repository
is certified new by this search.
